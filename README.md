# Sınıf Projeleri

Bu repo, öğrencilerin projelerini göndermesi için oluşturulmuştur.  
Lütfen aşağıdaki adımları takip edin:

## Adımlar

1. Repo’yu bilgisayarınıza clone edin:
git clone https://github.com/caglaytar/sinif-projeleri.git
cd sinif-projeleri

Adım 2: Kendi branch’ini oluştur

Her öğrenci kendi adına branch açacak
Örnek:

git checkout -b ali_kaya

Adım 3: Proje dosyalarını ekle

Kendi adını taşıyan bir klasör oluştur: Ali_Kaya_Projesi/

Tüm proje dosyalarını bu klasöre koy

Adım 4: Değişiklikleri commit ve push et
git add .
git commit -m "Ali Kaya projemi ekledim"
git push origin ali_kaya
